Details & installation

Customize artwork with a pre-made pack or use the EmbyTuneInArt tool to build your own.

Choose a ZIP on this computer. The server validates it and scans staged files with a supported local scanner when available. Review the pack and confirm before replacing the installed scope. If no scanner is available, explicit approval is required; scanner errors or threats block installation. Validation and scanning cannot guarantee malware-free images.

After installation choose Refresh now or Later. Genre artwork can affect both Music and Language; other packs affect their corresponding enabled categories. Refreshes can be blocked by active work or readiness.

Uploads require a flat ZIP containing only a strict tunein-artwork.json and the listed JPEG or PNG images, with matching IDs, counts and SHA256 hashes. Limits include 768 MiB per ZIP, 2 GiB expanded, 16 MiB per image and 4,096 pixels per dimension. The server needs its configured FFmpeg. See the README for the complete schema, limits, scanner requirements and troubleshooting.

Manual installation remains available: place image files and optional tunein-artwork.json in the corresponding server folder above, then refresh affected categories. Uploads require the strict manifest and archive layout documented in the README; older packs may need regeneration.

TuneIn levels: 3 to 50 (default: 10). The top-level category is level 0; every folder transition, including More Stations, adds one level. Additional depths allow traversing more stations, subject to Max Station Count. Reaching either limit still imports the limited discovery and retains existing entries allowed by saved filters. Retained deeper folders remain available; Emby import depth is not capped.
