Configure categories and selections, then save and enable browsing. New and upgraded installations do not automatically contact TuneIn.

Check this control and enable at least one category, then save. Categories requiring selections stay unavailable until you add and enable those selections.

Local Radio coordinates

Latitude -90 to 90, longitude -180 to 180. Coordinates are sent only for enabled coordinate-based Local Radio requests. No IP-location fallback.

Selections

Loading or expanding a selector explicitly contacts TuneIn. Some hierarchy responses include incidental station metadata, which is discarded. No streams are resolved, played or automatically crawled during setup. Available administrative levels vary by country. Choose Add at any offered level; Expand loads only that branch.

Disabled categories or categories with no required selections stay unavailable. Saving invalidates old navigation and stops applicable in-flight requests. Return to the channel root after saving or restarting Emby.

Refresh individual radio groups

Save changes first. Refresh fetches the first page for each enabled saved selection (or a group's starting page), then requests bounded Emby synchronization using those cached pages. Language includes a catalogue validation request. It does not crawl descendants, pagination or the worldwide catalogue, or play streams.

Progress counts completed API requests, not every TuneIn station or Emby's database import. HTTP status and returned station/link rows are reported; row counts are not a count of imported or unique stations. Status polling makes no TuneIn requests. Jobs continue when you leave this page; Cancel stops the chosen job. Saving configuration cancels applicable jobs. Jobs/status are held in memory and reset on server restart.
